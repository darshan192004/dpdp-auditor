# Fingerprint specification

> Frozen contract for finding identity across scans — `docs/rules.md` §8, implemented by
> `computeFingerprint()` in `packages/contracts/src/fingerprint.ts`.
> Changing anything below requires a `fingerprintVersion` bump and a migration story.

## Algorithm

```text
base = sha256(
  scanner + "|" +
  scannerRuleId + "|" +
  normalisedPath + "|" +
  snippetHash + "|" +
  occurrenceIndex
)
fingerprint = controlCode ? "fpt_" + base + ":" + controlCode : "fpt_" + base
```

| Input | Meaning |
|---|---|
| `scanner` | Scanner id (`checkov`, `semgrep`, `gitleaks`, …) |
| `scannerRuleId` | Rule id as reported by the scanner (`CKV_AWS_19`) |
| `normalisedPath` | Relative, POSIX-separated repository path |
| `snippetHash` | sha256 of the normalised matched lines, computed **without** the per-scan salt |
| `occurrenceIndex` | 0-based disambiguator for identical matches in the same file |
| `controlCode` | Present only on fan-out findings (one per mapped control) |

Digest format: `fpt_` + lowercase hex sha256 (64 chars), optionally `:` + control code.

## Stability rules

- **Line numbers are excluded.** A finding survives code moving down the file
  (`persistent`, not `new`).
- **`snippetHash` is salt-free.** Unlike `evidenceHash` (§7.1), the per-scan salt dies with
  the scan; the fingerprint must stay stable across scans for the
  new/persistent/resolved/reopened lifecycle.
- **The path is an input.** Renamed files produce a new fingerprint — the report labels them
  `new` rather than guessing a rename.
- **Fan-out shares the base.** Multiple mapped controls emit the same base with distinct
  `:DPDPA-…` suffixes; the bare base without a suffix is also valid when no control mapped.
- **`fingerprintVersion: 1`.** Exported as `FINGERPRINT_VERSION` from `@dpdpa/contracts`.
  Any change to the inputs, separator, or hash requires a bump.

## Control code format

`CONTROL_CODE_PATTERN = /^DPDPA-[0-9]+(?:\.[0-9]+)?-[A-Z0-9]+-[0-9]+$/` — matches the
catalogue format `DPDPA-<section>-<domain>-<sequence>` (e.g. `DPDPA-8.4-ENC-01`).

## Stored fingerprint validation

`FINGERPRINT_PATTERN = /^fpt_[0-9a-f]{64}(?::DPDPA-…)?$/` — used by
`normalisedFindingSchema.fingerprint`.

## Cross-scan status

| Previous | Current | Label |
|---|---|---|
| absent | present | `new` |
| present | present | `persistent` |
| present | absent | `resolved` |
| resolved | present | `reopened` |

Resolution joins on `fingerprint` within the same `repository_id`, against the most recent
completed scan (computed at scan completion).
